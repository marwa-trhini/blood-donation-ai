# Blood Donation App

University project (M1) — mobile application for blood donation management.

## Download BloodConnect

[Download Android APK — BloodConnect v1.0.0](https://github.com/marwa-trhini/blood-donation-ai/releases/tag/v1.0.0)

**Requirements:**
- Android 8.0 or later
- Internet connection required

## Tech Stack

| Layer        | Technology                          |
| ------------ | ----------------------------------- |
| Mobile       | React Native + JavaScript           |
| Backend      | Node.js + Express.js                |
| Database     | MongoDB + Mongoose                  |
| AI Service   | Python + FastAPI                    |
| ML           | scikit-learn                        |
| NLP          | Python                              |
| Auth         | JWT                                 |

## Project Structure

```
BloodDonationApp/
├── mobile/       # React Native mobile app
├── backend/      # Node.js + Express REST API
├── ai-service/   # Python FastAPI ML/NLP service
└── docs/         # Project documentation
```
